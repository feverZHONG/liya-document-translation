# 单章执行 · 续译/校验既有章节

> 2026-08-24 从 paper-translation skill 吸收。项目级并行分工（术语表→delegate 分章→抽查）见 SKILL.md 正文；本文档管「接到翻译第 X 章 / 续译 / 校验」时的单章执行细节。

## 什么时候用

- 收到「翻译论文/翻译第 X 章」任务
- 项目 `zh/` 目录已有多章译文 + `术语表.md`（多会话协作项目）
- 校验/续译既有章节

## 单章工作流

1. **读术语表**（项目 `zh/术语表.md` 或项目根）：术语对照 + 输出规范（标题格式、页码标记、证明处理、参考文献不译）。术语全文统一用表内译名；公式/数学记号保留原文。
2. **定位原文**：从 `paper-fulltext.txt` 按任务给的行号区间读取，每次 ~400-500 行分页读。
3. **翻译**：
   - 标题：`# N. 中文译名 (English Original)`，小节 `## N.M` / `### N.M.K`
   - 定义/定理/引理/推论：标题翻译、陈述尽量全译；**证明概括要点**（标「证明（要点）」），不逐行硬翻
   - 规则/伪代码：结构保留（``` 代码块），注释译中文
   - 参考文献条目（[39] 等）：保留原文不译
   - 编号公式（(37)-(64) 等）：放代码块保留原记号
4. **页码标记**：见下节。
5. **写入**：`zh/NN-中文名.md`。大章节（原文 >500 行）分 4-5 部分写临时文件再拼接：`cat _part1.md ... > 目标.md && rm _part*.md`。execute_code 可能被安全策略拦截时用 terminal 的 cat 拼接（cat 拼接已存在的文件是合法文件操作）。
6. **验证**：grep 章节标题齐全、`<!-- p.NN -->` 递增无缺号、定义/定理/引理编号完整（`grep -o '定理 [0-9]*' | sort -u -V`）。
7. **汇报**（按任务要求）：行数、覆盖原文位置（起始行→结束行，止于下一章标题行 -1）、公式乱码情况（还原了什么/哪里保留原样/有没有编造）。

## 页码标记（关键技巧）

PDF 提取的页界推导：

- 页脚数字出现在每页内容**末尾**（如行 1436 的 "28" = 第 28 页结束）
- `===== PAGE N =====` 分隔行出现在第 N 页内容**之前**
- 所以第 N 页内容 = 上一个 `===== PAGE N =====` 之后 → 页脚 "N" 之前
- `<!-- p.N -->` 标记放在每页内容**起始**处；原文跨页断句处可插在句中（HTML 注释不破坏排版）

**初稿装配后必须逐条核对标记位置**——首次装配几乎必然偏位 1-3 页（缺号、错位、整页后移）。核对法：把标记所在位置与原文页界映射表逐条比对；缺的号（p.33、p.35 这类）单独插入。

## 陷阱

- **页码标记偏位是最大翻车点**：装配后立即核对，别等汇报时才发现。修正用 V4A 多 hunk 补丁（锚点坑见 dev-workflow）
- **V4A 补丁锚点必须实测**：hunk 的 old_string 锚点假设（如「p.43 在 §4.4.3 前」）可能错误——先 read_file 确认目标内容实际位置再写 hunk；报「Found N matches for old_string」多半是锚点假设错（内容在别处）而非文本歧义
- **公式乱码**：PDF 提取的上标断裂（𝔈∗Γ 被拆两行）、公式折行，能按上下文还原就还原；无法还原保留原样；**禁止编造**（术语表明文规定）
- **图片**：论文插图（生命周期图等）提取只留标签文字，按正文描述重绘 ASCII 图并注明「重构自正文，非原图」
- **覆盖范围汇报**：确认章节结束位置（下一章标题行 - 1），别把下一章内容包进来
- **临时分片清理**：拼接后删 `_part*.md`，别留垃圾文件
